纯插件模式

轻巧独立

装进任意 DSH 0.2.x profile，直接在原生普通对话里使用。

普通会话直选人格
输入框旁新建、切换、右键重命名人格；已有普通会话也可绑定并自动提炼入库。
人格工作台管理
统一编辑人格设定、开关自动记忆、搜索与删改长期记忆，支持查看来源轮次。
从旧对话一键导入
选中未绑定或当前人格的历史会话导入记忆，后台排队提炼并自动去重。
严格范围隔离
不同人格按工作区隔离记忆；普通会话、子会话和无痕会话不写入、不注入。

完整 Bot 合并包

全功能协同

包含纯插件全部能力，额外提供侧栏频道、多人格群聊与工作区协同。

私聊工作过程时间轴
dot 与其他人格私聊共用无框折叠时间轴，实时展示工具步骤、耗时与显式摘要；额度不足直接给中文提示。
主人格查普通 DSH 历史
唯一主人格（dot）在本地私聊里可只读搜索普通 DSH 对话记录，其他人格与群聊默认隔离。
微信直觉群聊与抽屉
默认立即响应并显示已收到人数；右上角展开群聊抽屉，头像宫格、一键拉人与解散群聊集中管理。
群聊「全体」工作区授权与细粒度权限
右侧工作区点「全体」一键授权给全群人格（可选允许写入）；右键人格单独开关浏览器与电脑控制；内置 6 个纯本地原创人格模板。

快速上手

环境要求：DeepSeek Harness 0.2.x（桌面版或 Web 宿主）、Node.js ≥ 22.13（支持 node:sqlite）。

克隆仓库并打包纯插件 
git clone https://github.com/shinji00222/dsh-persona-continuity-bot.git
cd dsh-persona-continuity-bot
npm pack
  1. 把生成的 .tgz 通过 DSH 插件管理器安装到目标 profile，重启即可。
  2. 在 DSH 左侧面板打开 「人格工作台」，或在普通会话输入框旁点「普通会话」新建并切换人格。
  3. 新开会话直接说「继续上次」，即可召回该人格的本地 Markdown 记忆。
构建完整 Bot 合并包 
# 先构建好 Bot 层桌面产物（默认位于 dist/continuity-desktop/）
npm run pack:tobs   # 可用 TOBS_DIST=<目录> 指定桌面产物位置
  1. 生成 dist/dsh-persona-continuity-<版本>-with-tobs.tgz，请保留同目录的依赖文件夹。
  2. 安装前请先从目标 profile 卸掉旧的同类 Bot 插件，避免重复加载。
  3. 插件 ID 不变，从纯插件切换到合并包后，已有人格和本地记忆全部照常保留。

常见问题

记忆存在哪里？会上传到外部服务器吗？

不会上传。所有记忆都以纯 Markdown 存放在本地 $DSH_HOME/persona-continuity/memories/<personaId>/，无需 Git。提炼与召回只把必要正文发给当前会话配置的模型，插件本身不额外联网。

纯插件包和合并包怎么选？

平时只用 DSH 原生界面、只需要跨会话人格记忆，选纯插件包最轻巧；想要完整的侧栏频道、私聊时间轴、微信直觉多人格群聊和工作区协同，直接打合并包。

普通会话、子会话和无痕会话会被记住吗？

不会。只有主动绑定了人格的会话才会提炼和召回记忆；未绑定的普通会话、子会话和无痕会话默认完全隔离。

如何本地运行测试与验收？

运行 npm run check 做语法检查、npm test 跑单元测试；功能验收建议使用隔离的 DSH_HOME 启动 profile，避免影响日常配置。
