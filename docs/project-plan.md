# DSH 人格续忆项目规划

项目包名 `dsh-persona-continuity`，当前预览版 0.2.0-preview.13。来源和方案核对见 [调研](research.md)，模拟任务的方案见 [模拟任务规划](simulation-plan.md)。

## 首版体验

新会话默认是 DSH 普通会话，也可以在发送首条消息前选一个自己创建的人格。会话记住所选人格，两个同时打开的会话可以使用不同人格。各人格以稳定 ID 持有独立的长期记忆，改名仍沿用原记忆。

人格会话的成功轮次结束后，后台复用当前模型提炼并保存有长期价值的偏好、决定、进度、经验和事实。条目可在设置中查看、编辑和删除。

宿主为同一人格的相关请求选取少量历史笔记，提供摘要、详情、来源会话 ID 和轮次。「继续上次」会选取同人格最近一个有记忆的其他会话。普通会话、子会话和本机无痕插件格式的会话跳过这条记忆路径。

## 实现边界

- Cordis 插件负责在模型请求前安装人格设定和记忆上下文。设置页与输入框界面通过 DSH 插槽接入，管理路由复用 DSH 鉴权。
- SQLite 保存人格、会话绑定、长期记忆和后台任务。提炼任务以会话和轮次标识，可在宿主重启后继续处理。后台按人格、类别、主题和工作区合并新旧条目。
- 摘要优先显示当前工作区的近期条目，检索使用中文词片段、英文词和符号附近的编号。设置里的索引详情显示来源 ID 和轮次。
- 提炼失败按限定次数重试。检索和注入有数量上限。跨设备同步、语义检索和中途换人格留待后续。

## 各阶段目标

| 阶段 | 目标 | 验收 |
| --- | --- | --- |
| 0 · 接入验证 | 在隔离 profile 验证宿主、客户端资源、会话事件、工具和存储。 | 可在目标版本 Web 宿主注册插件，并通过浏览器访问设置和选择器。 |
| 1 · 人格与召回 | 支持创建、改名、选择和恢复人格，接上短摘要和详细索引。 | 两个并行会话的人格不同，普通会话保持原行为。重启后选回人格，首请求只获取该人格的摘要。 |
| 2 · 自动提炼 | 成功轮次在后台提炼并保存。 | 普通会话跳过提炼。验证重试、跨会话召回和删除。 |
| 3 · 试用包 | 打包，写试用说明，用桌面和真实模型测「继续上次」。 | 隔离验证通过后，再使用真实模型检查摘要是否能带来正确接续，并录下试用过程。 |
| 4 · 迭代 | 收集误召回、漏召回和成本问题。 | 用真实失败样本对照首版，在人格隔离和上下文预算下验证改进。 |

用记录型假模型验证实际请求和索引归属，用真实模型另行验证自然接续效果。

## 未来规划：本地总管首页（Home Dashboard）

在左侧导航栏新增「首页」面板，作为所有本地人格的统一总览与主人格（托布）快捷控制台，可与右侧对话面板并排联动：

1. **主人格快捷提问与常用指令**
   - 顶部提供「本地总管」快捷输入框，发送后直接路由给主人格（托布）并在右侧展开对话。
   - 预置高频快捷芯片：`帮我创建一个 Bot`、`看看我的 Bot 最近怎么样`、`有哪些事情需要我处理？`、`最近有哪些记忆更新？`。
2. **Token 用量统计卡片**
   - 汇总本机各人格的 Token 消耗，支持 `今日 / 7 天 / 4 周 / 12 周` 时间维度切换与手动刷新。
   - 按 `缓存读`、`其他输入`、`输出` 三类展示柱状图趋势。
3. **Bot 活跃情况总览**
   - 列出本机所有人格（头像、名称、当前状态如空闲/运行中/已暂停、最近活跃时间戳），支持点击直达对应私聊。
4. **主人格全局巡检能力**
   - 为唯一主人格（托布）补充只读巡检接口，可汇总全量人格的在线/暂停状态、模型配置、定位摘要、最近活跃情况与近期 Markdown 记忆更新，点击首页快捷指令即可给出结构化汇报。

### 验收口径

- 首页统计与状态全部来自本地数据（SQLite + 本地记忆目录），零外部网络请求。
- 快捷输入框与预置指令触发后，右侧对话可正确切换并展示托布回复；普通人格仍保持原有权限隔离。
